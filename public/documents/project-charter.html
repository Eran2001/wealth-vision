Project Charter

Project: Wealth Vision | Group: 25-26J - 535 | Faculty of Computing, SLIIT

Project Overview

Wealth Vision is an intelligent investor profiling and recommendation system that integrates risk tolerance, ESG preferences, and global market data to provide personalized investment guidance.

Scope

  • Investor profiling based on goals, risk appetite, time horizon, and ESG priorities.
  • ESG-aware scoring for global investment options.
  • Personalized recommendation generation using machine learning models.
  • Interactive dashboard for transparent recommendation review.

Expected Outcome

The project will deliver a working research prototype, evaluation results, documentation, and presentation materials suitable for academic assessment.
